# Immer mehr von dir

"Immer mehr von dir", das klingt nach Anspruch. Das klingt so, als ob ich doch messbar etwas leisten müsste, um Gott zu gefallen. Dabei ist es eigentlich ganz anders: "Immer mehr von dir" bedeutet, in die Freiheit, die Gott mir gibt hineinzuwachsen, beschenkt mit Glauben und zur Antwort in der Liebe getrieben.
